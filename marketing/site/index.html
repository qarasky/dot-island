THE SMALL PRINT

Before you
get attached.

Can I install it on my phone?+

This is an unpublished personal build, tested on one A069 running Android 16. The source is available, but compatibility with other phones isn’t promised. There is no public download or checkout here.

What access does it need?+

Accessibility access attaches the camera overlay. Notification access reads the supported activities and media state. Android grants are explicit. This website cannot change your phone’s settings.

Does it replace all my notifications?+

No. Ordinary notifications stay untouched. Generic Live Updates require explicit source approval; Dodo is the default supported delivery source. Source-provided status and ETA are displayed as received.

Is this actually a product launch?+

It is an actual app with a pretend product launch. There are no orders, mailing lists, fake reviews, or analytics on this page. You are welcome to admire the dot.
